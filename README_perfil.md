### 1. Andina Market 360

Proyecto académico orientado al análisis de
ventas ficticias de una empresa con sedes
en Lima, Ica y Arequipa.

**Objetivos:**
- Procesar registros de ventas.
- Calcular resultados por sede.
- Implementar pruebas automáticas.
- Presentar resultados en una página web.

**Tecnologías:** Python, Git, GitHub y HTML.

**Repositorio:** Pendiente de creación.

### 2. SHOWGO

Proyecto de desarrollo web para la gestión
de servicios y reservas.

**Objetivos:**
- Gestionar usuarios y servicios.
- Administrar reservas.
- Implementar operaciones mediante una API REST.
- Integrar el frontend con el backend.

**Tecnologías:** Java, Spring Boot,
PostgreSQL y Angular.

**Repositorio:** No especificado.
